# AI-Full-Stack Software Engineering

Welcome to my learning repository for the **AI-Full-Stack Software Engineering** programme.

This repository documents my assignments, exercises, projects, experiments, and progress throughout the programme as I build a strong foundation in software engineering.

My goal is not simply to learn web development. I am deliberately developing these skills to become a **Full-Stack GIS Software Developer** capable of building complete, scalable, and intelligent geospatial applications.

---

## About This Journey

My academic and professional background is in **GIS, Geospatial Science, Remote Sensing, and Data Analysis**.

I have worked extensively with spatial data, GIS software, remote sensing, geospatial analysis, and research. However, I want to go beyond using existing GIS platforms and develop the ability to **design, build, deploy, and maintain geospatial software myself**.

The AI-Full-Stack Software Engineering programme is an important part of that transition.

Through this journey, I am developing the software engineering foundation required to bridge the gap between **GIScience and software development**.

The long-term objective is to become a **Full-Stack GIS Software Developer** who can build applications that combine:

* Geospatial data
* Geographic Information Systems (GIS)
* Remote sensing
* Spatial analysis
* Web technologies
* Databases
* APIs
* Artificial intelligence
* Cloud technologies
* Software engineering

---

## My Goal

> **To become a Full-Stack GIS Software Developer capable of building modern, intelligent, and scalable geospatial applications from the frontend to the backend.**

I want to understand the complete software development lifecycle rather than limiting myself to a particular part of the technology stack.

This includes learning how to:

* Design user interfaces
* Build frontend applications
* Develop backend services
* Design and manage databases
* Build and consume APIs
* Implement authentication and authorization
* Deploy applications
* Work with cloud infrastructure
* Integrate artificial intelligence
* Work with spatial databases
* Build web mapping applications
* Process and serve geospatial data
* Develop GIS-based APIs and services
* Build complete geospatial products
