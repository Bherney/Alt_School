# Scissor – URL Shortener Landing Page

A responsive landing page for **Scissor**, a URL shortening service, built with plain HTML and CSS (no build step).

## Sections
- Hero with call to action
- Stats ("One Stop. Four Possibilities.")
- Why choose Scissors (features)
- Pricing (Basic, Professional, Teams)
- Trim URL form
- FAQs (accordion using `<details>`)
- Call to action and footer

## Run locally
Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## Deploy
Works as-is on GitHub Pages, Netlify or Vercel. For GitHub Pages: repo **Settings → Pages → Deploy from branch → main / (root)**.

## Tech
- HTML5, CSS3 (custom properties, grid, flexbox)
- Font: Plus Jakarta Sans (Google Fonts)
