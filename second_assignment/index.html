FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

No. You can shorten links without an account. Creating a free account lets you save, edit and track your links.

Are the shortened links permanent? Will they expire?

Links stay active by default. You can set an expiry date on any link if you only need it for a limited time.

Are there any limitations on the number of URLs I can shorten?

The Basic plan includes unlimited URL shortening. Paid plans add analytics, branded domains and team features.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Choose a custom alias for any link, and on paid plans use your own branded domain.

Can I track the performance of my shortened URLs?

Yes. Every link comes with analytics showing clicks, locations, devices and referrers over time.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

Links are scanned for known malicious destinations, and abusive links are disabled. Teams plans add enhanced security controls.

What is a QR code and what can it do?

A QR code is a scannable image that opens a link on a phone camera. Use it on posters, packaging or event materials to bring people straight to your page.

Is there an API available for integrating the URL shortening service into my own applications or websites?

Yes. API access is included in the Teams plan, so you can create and manage links from your own apps.
