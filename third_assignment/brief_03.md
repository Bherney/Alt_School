# Chatter – Text-Based Content Platform Landing Page

A responsive landing page for **Chatter**, a platform where writers and readers share and discover text-based content. Built from a Figma design with plain HTML and CSS (no build step).

## Live site
https://bherney.github.io/chatter-landing-page/

## Sections
- Navigation bar (collapses to a CSS-only hamburger menu on mobile)
- Hero: "Welcome to Chatter: A Haven for Text-Based Content"
- About Chatter
- Why you should join Chatter (Analytics, Social interactions, Content creation)
- Testimonial
- "Write, read and connect with great minds" call to action
- Footer (Explore, Support, Official blog)

## Run locally
Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## Deploy
Hosted on GitHub Pages from the [chatter-landing-page](https://github.com/Bherney/chatter-landing-page) repository (**Settings → Pages → Deploy from branch → main / (root)**).

## Tech
- HTML5, CSS3 (custom properties, grid, flexbox, media queries)
- Font: DM Sans (Google Fonts)
- Illustrations drawn with inline SVG
